# Политика конфиденциальности

**Последнее обновление:** 15 апреля 2026

## Главное

**Мы не видим содержимое ваших списков.** Всё зашифровано на вашем устройстве ключами из iCloud Keychain до того, как попасть в облако. Ни разработчик, ни Apple, ни кто-либо ещё не может прочитать ваши вишлисты, желания, цены, ссылки, картинки или описания.

## Что мы собираем

### Ничего не собираем мы сами

Приложение **не отправляет никаких данных** на сервера разработчика. У нас нет своего бэкенда, нет аналитики, нет трекинга, нет рекламы.

### Что хранится в iCloud

Ваши данные синхронизируются между вашими устройствами через **ваш собственный iCloud** (Apple). Это происходит напрямую между устройствами и Apple — разработчик не имеет доступа к этим данным.

Все пользовательские данные шифруются методом **end-to-end encryption** с использованием ключей, которые хранятся в вашем iCloud Keychain. Apple не может расшифровать ваши данные — ключи только у вас.

### Что может знать разработчик (только через CloudKit Dashboard)

- **Количество активных iCloud-пользователей приложения** (агрегированная цифра без идентификации)
- **Объём использованной квоты** (в МБ, без содержимого)
- **Технические события**: успешные/неуспешные синхронизации (без данных)

Ни имя пользователя, ни содержимое данных, ни метаданные файлов разработчику не доступны.

## Имя пользователя (discoverability)

При первом запуске приложение спрашивает разрешение узнать ваше имя из iCloud. Это нужно только для:
- Отображения вашего имени в списке участников общего вишлиста
- Приветствия в интерфейсе приложения

**Имя остаётся на вашем устройстве** и отправляется только тем, с кем вы явно делитесь списком (через CKShare от Apple).

Можно отказаться — приложение продолжит работать, просто будет показывать "Вы" вместо имени.

## Шеринг вишлистов

Когда вы делитесь вишлистом с другим человеком:
- Apple создаёт защищённый CKShare — это механизм Apple для совместного доступа
- Ключи шифрования безопасно передаются через iCloud Keychain участников
- Разработчик не видит ни вас, ни участников, ни содержимое

## Разрешения, которые запрашивает приложение

| Разрешение | Зачем |
|------------|-------|
| Камера | Сфотографировать обложку желания или отсканировать QR-код приглашения |
| Галерея | Выбрать фото для обложки желания |
| Уведомления | Напомнить о конце испытательного срока желания (по желанию) |
| iCloud | Синхронизация списков между вашими устройствами |

Все разрешения опциональны — без них приложение работает, просто некоторые функции недоступны.

## Ваши права

- **Удалить все данные**: удалите приложение — локальные данные сотрутся. Чтобы удалить из iCloud — Настройки → Apple ID → iCloud → Управление хранилищем → I Wish → Удалить.
- **Экспорт данных**: через CloudKit Dashboard Apple доступен экспорт ваших записей (на стороне Apple, не через разработчика).
- **Отозвать шеринг**: любой созданный shareлинк можно отозвать в любой момент через приложение.
