# Пользовательское соглашение

**Последнее обновление:** 15 апреля 2026

## Что такое I Wish

I Wish — приложение для ведения персональных и общих списков желаний. Работает на iOS 26+, использует iCloud для синхронизации и шеринга.

## Принцип работы

Приложение бесплатное, без рекламы, без подписок, без покупок внутри. Разработчик не получает доход от приложения.

## Ваши обязанности

- Использовать приложение по назначению (ведение списков желаний)
- Не использовать для хранения незаконного контента
- Не использовать для спама, мошенничества или преследования других пользователей

## Ограничения ответственности

- Данные хранятся в вашем iCloud. Если Apple теряет данные — это проблема Apple, не разработчика.
- Если ваш вишлист случайно удалён участником с правами редактора — восстановление возможно только через iCloud-backup Apple.
- Разработчик не гарантирует бесперебойную работу приложения. Любые обновления могут ломать обратную совместимость (с предупреждением).

## Шеринг

- Создавая общий вишлист, вы соглашаетесь поделиться его содержимым с участниками
- Участники получают тот уровень доступа, который вы выбрали (редактор или просмотр)
- Владелец может отозвать доступ в любой момент
- Срок жизни приглашения (TTL) настраивается — после истечения ссылка недействительна

## Собственность

Все ваши данные принадлежат вам. Разработчик не получает права на ваш контент.

Исходный код приложения — open source: https://github.com/RUGyron/I-Wish-App

## Прекращение использования

Можете в любой момент удалить приложение. Данные в iCloud останутся до их ручного удаления через настройки Apple.
